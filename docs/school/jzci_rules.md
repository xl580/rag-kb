# 晋中信息学院学生管理相关规章制度

## 一、晋中信息学院学生日常行为规范

一、遵守宪法和国家法律、法规以及学校规章制度，自觉维护社会稳定和校园秩序。
二、坚持社会主义、集体主义。关心集体，积极参加集体活动，不做有损于学校和集体荣誉的事，顾全大局，个人利益要服从国家利益、集体利益。反对极端个人主义。
三、坚持实事求是原则。说话要有事实根据，办事要从实际出发，要如实反映情况，不弄虚作假，正确开展批评与自我批评。
四、发扬艰苦奋斗精神。勤俭节约，不浪费水、电、粮食，热爱劳动，自立自强，积极参加校内外公益活动和勤工助学活动。
五、注意个人品德修养。衣着整洁，朴素大方，谦虚谨慎，礼貌待人，诚实守信，尊重他人，语言文明，不讲粗话脏话，尊敬师长，团结同学，男女交往，举止得体，讲究社会公德，敢于和不良行为作斗争。
六、维护教学秩序，培养优良学风。勤奋学习，刻苦钻研；遵守学习纪律，按时上、下课，独立完成作业，考试不作弊，积极参加第二课堂活动。
七、自觉维护公共秩序，遵守公共场所有关规定。不打架斗殴，不起哄闹事，不赌博，不吸烟，不酗酒，不观看、传播反动、淫秽书刊和音像制品，不上黄色网站。
八、遵守宿舍管理规定。维护宿舍秩序和卫生，树立安全意识，不违章用电用火，不私自留宿他人。积极参加宿舍文化建设和创建 “星级文明宿舍” 活动，努力营造良好的集体生活环境。
九、爱护公共财物，保护公共设施，爱护校园花草树木。不乱刻乱写，不乱抛废弃物，不随地吐痰，损坏公物要自觉赔偿。
十、养成良好的生活习惯。搞好个人卫生，维护公共卫生。积极参加体育锻炼和健康有益的文化娱乐活动，增进身心健康。

## 二、学生违纪处分等级

违纪处分分为五种：警告、严重警告、记过、留校察看、开除学籍。
学生有违纪行为，但情节轻微不足以给予违纪处分的，由学生所在学院给予通报批评，督促其改正错误，如屡次违纪应给予相应违纪处分。

从轻处分条件：

1. 能主动如实陈述错误事实，确有悔改表现的，可从轻处分；
2. 受他人胁迫或诱骗，认错认罚态度好的，可从轻处分；
3. 能够积极协助调查处理，主动检举同案者或其他应当受到处分者的违纪行为，或有其他立功表现的，经查实可减轻处分；
4. 主动挽回损失或有效阻止危害结果发生的，可免予处分。

从重处分：违纪事实确凿但拒不承认错误、多次违纪、教唆他人违纪、对检举人打击报复等情况，应当从重处分。

## 三、考试违纪处理规定

1. 给予**记过处分**的作弊行为：携带并抄袭与考试内容相关的文字材料或者电子材料；抄袭或协助他人抄袭试题答案；传递、交换考试相关资料；使用手机通讯设备传递答案；偷看他人试卷或有意让他人抄袭试卷；课桌上写考试相关内容；两份答卷雷同率 80% 以上；在试卷外标记个人信息；拒绝妨碍考务人员工作；故意损坏考试设施情节严重。
2. 给予**开除学籍**的作弊行为：替别人考试或找他人替考；组织他人考试作弊；利用无线耳机等高科技设备作弊；网络作弊后果严重；其他情节特别严重、态度恶劣的作弊。

## 四、打架斗殴违纪处理

1. 组织策划怂恿打架：造成不良影响留校察看；造成严重后果开除学籍；伙同校外人员到校滋事，未打架留校察看，一旦发生打架，一律开除学籍并移交公安。
2. 动手打人未伤人：严重警告或记过；致轻伤：记过或留校察看；致重伤：开除学籍。先动手打人，从重处分。
3. 以劝架为名偏袒一方，扩大事态造成后果：视情节给予严重警告、记过、留校察看，严重者开除学籍。结伙斗殴没有伤人，给予留校察看。

## 五、学生校内申诉办法

1. 制定依据：《教育法》《普通高等学校学生管理规定》以及本校《学生违纪处分管理规定》。
2. 申诉原则：实事求是、有错必纠。学生对同一处分决定，校内申诉只能申请一次。
3. 学校设立学生申诉处理委员会，专门受理学生申诉。申诉人不能伪造证据、诬陷他人，不能扰乱教学秩序。
4. 申诉委员会复查后，如果原处分程序违法、证据不足、定性错误、处分明显不当，会提出变更建议，提交学校重新研究。

## 六、学生处职能介绍

学生处下设一科一室三中心：学生管理科、军事理论教研室、学生资助管理中心、心理健康教育中心、学生公寓服务中心。
主要职责：学生思政教育、辅导员队伍建设、学生管理规章制度制定、奖勤助贷资助管理、心理健康教育、征兵宣传、学生证办理、宿舍公寓管理、新生军训入学教育、毕业生离校工作、校园安全宣传。

## 七、宿舍管理红线（日常行为规范摘录）

宿舍禁止违章用电、使用明火，禁止私自留宿外来人员。积极参与星级文明宿舍评比。
